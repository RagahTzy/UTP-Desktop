FITUR YANG TELAH DIIMPLEMENTASIKAN - AO (AOKIKEN)
===============================================================================

✅ WINNER HANDLERS:
   - BtnAoKiken: Jika dipencet → AO menjadi winner
   - BtnAoShikkaku: Jika dipencet → AO menjadi winner

✅ KNOCKED OUT:
   - BtnAoKnockedOut: Jika dipencet → Menampilkan Knocked Out Countdown (09)

✅ PENALTY BUTTONS (Berubah ke warna BIRU):
   - BtnAo1C: Jika dipencet → Tombol 1C berubah biru
   - BtnAo2C: Jika dipencet → Tombol 1C dan 2C berubah biru
   - BtnAo3C: Jika dipencet → Tombol 1C, 2C, dan 3C berubah biru
   - BtnAoHC: Jika dipencet → Tombol 1C, 2C, 3C, dan HC berubah biru
   - BtnAoH: Jika dipencet → Tombol 1C, 2C, 3C, HC, dan H berubah biru, AO menjadi winner

✅ SPECIAL BUTTONS:
   - BtnAoVR: Jika dipencet → Tombol berubah KUNING
   - BtnAoSenshu: Jika dipencet → Tombol berubah KUNING

✅ SCORE TRACKING:
   - BtnAoYuko: Jika dipencet → Tambah (1)-Yuko ke DgvAoHistory dengan timer, update LblAoMainScore
   - BtnAoWazaari: Jika dipencet → Tambah (2)-Waza-ari ke DgvAoHistory dengan timer, update LblAoMainScore
   - BtnAoIppon: Jika dipencet → Tambah (3)-Ippon ke DgvAoHistory dengan timer, update LblAoMainScore
   - LblAoMainScore: Otomatis update sesuai total score di DgvAoHistory

✅ RESET & DISPLAY:
   - BtnAoResetScore: Jika dipencet → Semua data di DgvAoHistory dihapus, LblAoMainScore = 0
   - BtnAoShowWinner: Jika dipencet → Menampilkan winner dengan nama, team, dan team info

✅ DATA SELECTION:
   - BtnAoUserIcon1 (atau BtnAoIcon): Buka ListofCompetitor → Isi TxtAoNameMain, TxtAoTeam, TxtAoTeamInfo
   - BtnAoSearch2: Buka ListofTeam → Isi TxtAoTeam dan TxtAoTeamInfo

   - BtnAkaVR → Tombol berubah kuning
   - BtnAkaSenshu → Tombol berubah kuning
   - BtnAkaYuko, BtnAkaWazaari, BtnAkaIppon → Track score
   - BtnAkaResetScore → Reset score history
   - BtnAkaShowWinner → Tampilkan winner
   - BtnAkaUserIcon1 → Pilih competitor
   - BtnAkaSearch2 → Pilih team

===============================================================================
FITUR DATA GRID (DgvAoHistory & DgvAkaHistory)
===============================================================================

✅ Kolom yang Tersedia:
   - ColNo: Nomor urut otomatis (1, 2, 3, ...)
   - ColTimer: Waktu dari LblMatchTimerValue.Text
   - ColType: Jenis score: "(1)-Yuko", "(2)-Waza-ari", "(3)-Ippon"

✅ Score Calculation:
   - (1)-Yuko = 1 poin
   - (2)-Waza-ari = 2 poin
   - (3)-Ippon = 3 poin
   - Total ditampilkan di LblAoMainScore / LblAkaMainScore
